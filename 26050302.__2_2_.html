26050302.例题2(2) 求下列函数的值域： y = \sin \left( x + \frac{\pi}{6} \right), x \in \left[ -\frac{\pi}{3}, \frac{\pi}{2} \right]<br>★★★☆☆<br>正弦型函数 y = A\sin(\omega x + \phi) 的性质、整体换元法、正弦函数在特定区间上的单调性与最值。<br>重点：通过整体换元确定“复合角”的取值范围。 难点：准确结合正弦函数图象判断在该范围内的增减性，从而确定最大值和最小值。<br>首先观察函数解析式，自变量 x 所在的相位是一个整体，因此首要方向是使用整体换元法。先由 x 的取值范围推导出 x + \frac{\pi}{6} 的范围，将其视作一个新变量 t。接着，在正弦函数 y = \sin t 的图象中截取对应 t 范围的一段，通过观察图象的波峰、波谷或端点来确定 y 的上下界。<br>考查学生对三角函数“整体思想”的掌握程度，以及对正弦函数图象变换及区间最值的理解。<br>“整体换元，图象辅助”。将复杂的括号内部分看作一个整体，简化为基本初等函数。在判断最值时，务必检查 \frac{\pi}{2} + k\pi（最值点）是否落在新变量的区间内。<br>这是一道基础的复合三角函数求值域问题，是后续学习更复杂函数性质的基石。<br>直接代入端点值。很多同学会习惯性地只计算 x = -\frac{\pi}{3} 和 x = \frac{\pi}{2} 时的函数值，从而忽略了区间内包含正弦波峰（最大值 1）的情况。<br>若将函数改为 y = \cos \left( x + \frac{\pi}{6} \right)，同样的 x 范围，换元后的 t 范围不变，但需根据余弦函数的图象重新寻找最高点和最低点。
